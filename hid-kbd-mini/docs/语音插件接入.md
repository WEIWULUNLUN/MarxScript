# 语音录入（微信同声传译插件）接入

小程序端代码已经写好了，**只差后台添加插件 + app.json 声明两步**。没做这两步时，占位接口保留、
首页语音按钮会提示「语音未启用」，其它功能照常。

## 1. 后台添加插件

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 设置 → 第三方设置 → 插件管理 → 添加插件
2. 搜索「**微信同声传译**」，申请使用（一般即时通过）
3. 记下插件的 AppID 与版本号（以插件详情页显示的为准，别凭记忆填）

## 2. app.json 声明

在 `app.json` 顶层加（版本号填插件详情页上的最新版，此处仅为示例，**需以官方文档核实**）：

```json
{
  "plugins": {
    "WechatSI": {
      "version": "0.3.5",
      "provider": "wx069ba97219f66d99"
    }
  }
}
```

声明后 `pages/index/index.js` 里的 `requirePlugin('WechatSI')` 才能拿到实例，代码不用改。

## 3. 代码里用到的接口

```js
const plugin = requirePlugin('WechatSI')
const mgr = plugin.getRecordRecognitionManager()

mgr.onStart = () => {}          // 开始录音
mgr.onRecognize = (res) => {}   // 实时中间结果 res.result
mgr.onStop = (res) => {}        // 最终结果 res.result
mgr.onError = (err) => {}       // err.msg / err.retcode

mgr.start({ duration: 60000, lang: 'zh_CN' })
mgr.stop()
```

对应实现见 `pages/index/index.js` 的 `initVoice / onVoiceStart / onVoiceEnd`。

## 4. 权限与合规

- 录音前必须拿到 `scope.record`，代码里已做 `wx.authorize` + 拒绝后引导 `wx.openSetting`。
- 后台「用户隐私保护指引」必须声明**麦克风**用途（以及蓝牙、位置），否则审核会因隐私接口被拒。
- 语音识别在腾讯侧完成，识别结果只回到本机内存/输入框，不再上传、不落盘 —— 这一点在设置页的隐私说明里已写明。
- 微信原生**不提供离线语音识别**，医院无外网时语音功能不可用，此时用键盘手输（GBK 转码本身是离线的，不受影响）。

## 5. 备选方案

如果插件审核不通，可换云开发语音识别（需要联网），入口同样留在 `initVoice`：
把 `plugin` 换成 `wx.cloud.callFunction` 即可，UI 与后续流程无需改动。

## 6. 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| `requirePlugin` 报错 / undefined | app.json 没声明或后台没添加插件 | 完成第 1、2 步 |
| 录音没反应 | 用户拒过麦克风权限，后续 `wx.authorize` 会直接失败 | 引导 `wx.openSetting` 打开 |
| 识别结果乱 | 环境噪声大 / 说得太快 | 已做「识别后手动改字」，别跳过这一步 |
| 真机没声音 | 手机静音不影响录音，但部分机型需要先授权过任一录音场景 | 重启小程序重试 |
