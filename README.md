# MarxScript

把手机里的中文长文本，通过 BLE 无线「敲」进电脑的 USB HID 键盘方案。

面向医院内网隔离终端：目标电脑只需识别一个标准 USB HID 键盘，无需安装输入法、驱动、客户端，也不需要管理员权限。文字在手机本地转换成击键指令，经低功耗蓝牙下发给 CH582F 设备，由设备按标准键盘协议输入到当前光标位置。整个过程不经过任何服务器。

## 工作原理

1. 小程序扫描并连接 CH582F，建立自定义 GATT 服务的写通道与通知通道。
2. 正文在本地完成字符编码转换：汉字与特殊符号映射为十进制码位（由设备用 Alt + 小键盘注入），可由键盘直接产生的字符映射为 HID 按键或组合键。
3. 长文本按当前链路容量切分为批次，以无响应写方式连续下发；设备用独立定时任务控制击键节奏，把 BLE 抖动与按键时序解耦。
4. 设备按累计完成序号回报进度，单条回执丢失不阻断后续发送；收尾阶段通过与设备侧队列水位对账结算未上屏字符，避免中途误判造成重复输入。

协议细节见 `hid-kbd-mini/docs/PROTOCOL.md`。

## 快速开始

### 小程序

1. 微信开发者工具 → 导入 `hid-kbd-mini/`。
2. `project.config.json` 的 `appid` 是占位值 `touristappid`（无 AppID 模式，仅能跑模拟器）。真机调试或上传前请改成你自己的小程序 AppID，并在微信公众平台把自己加为项目成员。
3. 若使用自编译固件，核对 `utils/config.js` 中的 `SERVICE_UUID / WRITE_UUID / NOTIFY_UUID` 与固件一致；默认 `FFE0/FFE1/FFE2`。
4. 手机打开蓝牙 → 设备页扫描连接 → 首页输入或粘贴文字 → 把电脑光标点进目标输入框 → 发送。

### 固件

1. 直接烧录 `KBD582/firmware/KBD582_v44_20261114-1951.hex`（WCH-Link 或 WCH ISP 工具），无需编译。
2. 若要改源码：用 MounRiver Studio 打开 `KBD582/`，把 `.project` 与 `KBD582.wvproj` 中 `linkedResources` 的占位路径 `SDK_ROOT/EVT/EXAM/...` 改成本机沁恒 CH58x `EVT/EXAM` SDK 的实际位置，再编译。

## 已知限制

- 键位表按 **US 键盘布局**设计；非 US 布局下带 Shift 的符号位置可能偏移。
- 汉字依赖目标系统接受 Alt + 小键盘十进制码注入。Word 等支持 Alt code，部分自绘输入框或 Web/Electron 应用可能不支持；此类环境下纯 ASCII 标点可走 HID 按键直输。
- 设备绑定为「第一台手机占用」，解绑需断电或按 RST；当前协议未提供 `UNBIND` 命令。
- 本仓库是 **V1.0 开源基线**，功能集合与作者日常使用的完整工程不同：`hid-kbd-mini/` 内不含宏页面、设备鉴权输入卡片、速度自定义档位、诱饵密钥显示、真机调试桥与自检工具；源码中的技术注释已剥离，但第三方法律声明头完整保留。
- 预编译 `.elf` / `.map` 中含编译时的调试符号路径信息。
